# docs/

Supplementary documentation and assets for Pulse.

## Screenshots

The main `README.md` references two images that live here:

- `dashboard.png` — the main dashboard (stat cards, chart, explain panel, source badge)
- `about.png` — the About & Sources page

To capture them: run the app locally (`uvicorn` + `npm run dev`), open
<http://localhost:5173>, and save full-page screenshots of the dashboard and the
About page into this folder with those filenames.
